# 5PDM

Eu usei o arquivo "Relógio" como inspiração para criar este pequeno jogo. Ele consiste basicamente em testar seus reflexos ou intuição tentando parar o tempo de um cronômetro num valor mais próximo possível de uma referência entregue pelo jogo, quanto mais próximo do objetivo o seu resultado for, maior será sua pontuação, se seu valor for longe demais você perde e sua pontuação é zerada. O jogo vem com a opção de você jogar vendo ou não o cronômetro que você controla.
